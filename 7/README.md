# Лабораторная работа №7: Управление состоянием сеанса и обеспечение безопасности клиентских кук

## Описание
Подсистема управления сессиями и безопасностью cookie, демонстрирующая комплексную защиту от атак Session Hijacking, Session Fixation, Cookie Tampering и XSS.

## Архитектура безопасности
1. **Криптографическая подпись cookie:** HMAC-SHA256 с валидацией через `crypto.timingSafeEqual` для предотвращения атак по времени.
2. **Флаги безопасности cookie:** `HttpOnly` (защита от кражи через XSS в браузере), `SameSite=Lax` (защита от CSRF), `Max-Age` (ограничение времени жизни), `Secure` в production.
3. **Защита от Session Fixation:** Обязательная регенерация ID сессии с переносом данных при успешной аутентификации (`/api/auth/login`).
4. **Контроль времени жизни:** Поддержка времени бездействия (`idleTimeout`) и абсолютного времени жизни (`absoluteLifetime`).
5. **Session Fingerprinting:** Проверка соответствия связки IP + User-Agent отпечатку сессии.
6. **Корректный Logout:** Очистка серверного хранилища и аннулирование cookie на клиенте (`Max-Age=0`).

## Запуск
- Установка зависимостей: `npm install`
- Запуск сервера: `npm start`
- Запуск тестов: `npm test`
