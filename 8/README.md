# Лабораторная работа №8: Проектирование систем аутентификации и разграничения прав доступа

## Описание
Корпоративная система документооборота (DMS) с реализацией современной архитектуры безопасности:
Dual-Token Authentication (JWT + Refresh Tokens), Refresh Token Rotation (RTR), Reuse Detection, а также гибридной модели разграничения доступа RBAC + ABAC (Ownership).

## Ключевые механизмы
1. **Dual-Token Pattern:** Краткоживущий Access Token (JWT HS256, 15 мин) и долгоживущий криптостойкий Refresh Token (7 дней).
2. **Refresh Token Rotation (RTR):** При каждом обновлении токена выдается новая пара, а старый токен аннулируется в цепочке (`familyId`).
3. **Reuse Detection (Защита от кражи сессии):** При попытке повторного использования отозванного токена сервер немедленно инвалидирует всю цепочку сессий пользователя.
4. **RBAC & ABAC:** Разделение ролей (`USER`, `MANAGER`, `ADMIN`) и уровней классификации документов (`PUBLIC`, `INTERNAL`, `CONFIDENTIAL`) с проверкой авторства ресурса.
5. **Журнал аудита безопасности (AuditLog):** Фиксация событий входа, создания, удаления ресурсов и детекции атак.

## Запуск
- Установка зависимостей: `npm install`
- Запуск сервера: `npm start`
- Запуск тестов: `npm test`
