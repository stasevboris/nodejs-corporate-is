# Лабораторная работа №3: Реализация событийно-ориентированных подсистем и обработка потоков данных

## Описание
Потоковый аудитор безопасности и санитайзер серверных журналов доступа.
Реализован на нативных подсистемах Node.js (`node:events`, `node:stream`).

## Ключевые возможности
- Класс `AuditMonitor` (`EventEmitter`): сигналы тревоги `security:alert` (SQLi, XSS, Path Traversal), пороговые триггеры `threshold:exceeded`, агрегация статистики `pipeline:complete`.
- `ParserStream` (`Transform`): потоковый разбор NDJSON с корректным накоплением и обработкой чанков, разорванных границами буфера.
- `SanitizerStream` (`Transform`): потоковое маскирование PII (IP-адреса, адреса электронной почты, Bearer токены авторизации).
- `ReportWriter` (`Writable`): сохранение очищенного журнала и контроль backpressure (`drain` события).
- Конвейеризация через `stream/promises.pipeline` без полной загрузки файла в ОЗУ.

## Запуск
- Запуск обработки: `npm start`
- Генерация тестовых логов: `npm run generate-logs`
- Запуск тестов: `npm test`
