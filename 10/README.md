# Лабораторная работа №10: Организация дуплексного сетевого взаимодействия в реальном времени

## Описание
Полнодуплексный сетевой сервис реального времени на протоколе WebSocket (RFC 6455) на базе библиотеки `ws` и встроенного модуля `node:http`.

## Архитектура сетевого взаимодействия
1. **Аутентификация при Upgrade:** Проверка подлинности JWT в URL запроса до завершения рукопожатия WebSocket (при ошибке сокет немедленно обрывается со статусом `401 Unauthorized`).
2. **Envelope Pattern:** Строгая структура сообщений `{ id, type, payload, timestamp, ack, replyTo }`.
3. **Изоляция комнат (Rooms):** Подписка `room:join`, отписка `room:leave` и широковещательная рассылка событий внутри комнат.
4. **Индикатор набора текста (Typing):** Рассылка уведомлений участникам комнаты с фильтрацией эха отправителю (`excludeWs`).
5. **Адресные сообщения (Direct Messaging):** Доставка сообщений конкретному подключенному клиенту по его идентификатору.
6. **Подтверждение доставки (ACK):** Асинхронные квитанции доставки на пакеты с флагом `ack: true`.
7. **Heartbeat (Keep-Alive):** Регулярный опрос сокетов фреймами `ping` и принудительное отключение неактивных клиентов (`ws.terminate()`).
8. **Интерактивный Web UI:** Веб-клиент с чатом и инспектором пакетов протокола (`public/index.html`).

## Запуск
- Установка зависимостей: `npm install`
- Запуск сервера: `npm start`
- Запуск тестов: `npm test`
