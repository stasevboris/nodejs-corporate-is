# Лабораторная работа №4: Низкоуровневое программирование HTTP-сервера средствами системных модулей

## Описание
Полноценный REST HTTP-сервер задач, реализованный без использования Express или сторонних роутеров.
Используются исключительно стандартные модули: `node:http`, `node:fs`, `node:url`, `node:path`.

## Особенности
- Собственный класс `Router` с поддержкой параметров маршрута (`/api/tasks/:id`).
- Потоковый разбор JSON с лимитом размера 1 МБ (`413 Payload Too Large`).
- Защита от Path Traversal при отдаче статики (`/public/*`, `403 Forbidden`).
- CORS preflight (`OPTIONS` -> `204 No Content`).
- Полный жизненный цикл CRUD задач (`200`, `201`, `204`, `400`, `404`, `500`).
- Интерактивный веб-интерфейс в `public/index.html`.

## Запуск
- Запуск сервера: `npm start`
- Запуск тестов: `npm test`
