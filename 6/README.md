# Лабораторная работа №6: Интеграция базы данных и реализация персистентного слоя приложения

## Описание
Архитектурный слой персистентности данных складского учёта на базе SQLite (`node:sqlite`).

## Особенности реализации
- Включение строгой поддержки внешних ключей (`PRAGMA foreign_keys = ON;`) и режима WAL.
- Модули миграции (`src/db/migrations.js`) и наполнения тестовыми данными (`src/db/seeds.js`).
- Паттерн Репозиторий (`CategoriesRepository`, `ProductsRepository`, `InventoryLogsRepository`).
- Сервисный уровень с атомарной транзакцией `adjustStock()`: одновременное изменение остатка товара и запись в журнал аудита `inventory_logs`.
- Гарантированный откат (`ROLLBACK`) при недостатке остатков (`CHECK (stock >= 0)`) или сбое валидации.

## Запуск
- Запуск демонстрационного сценария: `npm start`
- Запуск тестов: `npm test`
