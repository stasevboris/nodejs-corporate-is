# Лабораторная работа №5: Диспетчеризация сетевых запросов и конвейеризация данных в Express

## Описание
REST API службы технической поддержки (Tickets Helpdesk Service), демонстрирующий построение строго упорядоченного конвейера middleware в фреймворке Express.

## Архитектура конвейера (Middleware Pipeline)
1. `X-Request-Id` генерация и проброс через заголовки.
2. Профилирование времени ответа (`X-Response-Time`) и логирование событий `finish`.
3. `express.json()` с обработчиком синтаксических ошибок JSON.
4. Общие заголовки безопасности (`nosniff`, `DENY`).
5. Роутинг модулей (`/api/v1/tickets`).
6. Валидация параметров маршрута через `router.param('id')` с проверкой UUIDv4.
7. DTO валидаторы создания и обновления сущностей.
8. Санитизация строковых полей и нормализация тегов.
9. Централизованный обработчик ошибок (RFC-совместимый JSON, скрытие стека в production).

## Запуск
- Установка зависимостей: `npm install`
- Запуск сервера: `npm start`
- Запуск тестов: `npm test`
