# Лабораторная работа №1: Развертывание окружения и конфигурация модульной системы Node.js

## Описание
Диагностическое консольное приложение, демонстрирующее:
- Настройку ESM-проекта (`"type": "module"` в `package.json`).
- Взаимодействие ESM и CommonJS (импорт `.cjs` из ESM, динамический `import()`, `createRequire`).
- Top-level `await` и использование `import.meta.url`.
- Парсинг конфигурации `.env` и безопасную обработку переменных окружения.
- Мониторинг системных метрик (`node:os`, `node:process`).

## Запуск
- Запуск приложения: `npm start`
- Вывод системной информации: `npm run info`
- Вызов CJS утилиты: `npm run start:cjs`
- Запуск тестов: `npm test`
