# Корпоративная информационная система на Node.js

Десять модулей, которые в `app/` собраны в одно приложение.

| № | Тема |
|---|------|
| 1 | Окружение, ESM и CommonJS, переменные окружения, системные метрики |
| 2 | CLI-утилиты и автоматизация ОС: `sysops info / exec / pipeline` |
| 3 | Событийные подсистемы и потоки данных |
| 4 | HTTP-сервер на системных модулях без фреймворка |
| 5 | Маршрутизация и конвейеры middleware в Express |
| 6 | Персистентный слой и база данных |
| 7 | Сессии и безопасные cookie |
| 8 | Аутентификация и разграничение прав (RBAC) |
| 9 | REST-сервис с валидацией (контроллеры и репозитории) |
| 10 | Дуплексное взаимодействие в реальном времени (WebSocket) |

**Стек:** Node.js (ESM), Express, node:test. Около 7,3 тыс. строк JS.

```bash
npm install --prefix app
npm start            # веб-приложение
npm test             # тесты
npm run sysops -- info
```

Каждая папка `1`–`10` запускается отдельно, у каждой свой README.
